# AGENTS.md — SFT Data Ingestion
> https://agents.md/

When making significant changes to this codebase, always produce:

## 1. Architectural Decision Records (ADRs)

For each key decision, document:
- **Context** — what problem prompted the decision
- **Decision** — what was chosen
- **Tradeoffs** — a comparison table of alternatives (chosen option bolded)
- **Consequences** — what becomes easier or harder as a result

## 2. Implementation Plan

For any non-trivial feature or refactor, provide:

- **Design overview** — what the change does and why
- **Class diagram** — key types, interfaces, and their relationships (ASCII)
- **Entity relationship diagram** — data entities and cardinality (ASCII)
- **Implementation steps** — ordered, with specific file paths for each step
- **Verification** — how to test the change end-to-end
